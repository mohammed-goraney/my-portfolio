# Portfolio

This repository contains a portfolio project scaffolded with a clean architecture and separation of concerns.

## Structure

- `src/types/` — Type definitions for the portfolio data.
- `src/data/` — Static content data used by the site.
- `src/constants/` — Design tokens, navigation, and metadata.
- `src/components/` — Reusable UI components and sections.
- `src/hooks/` — Custom React hooks.
- `src/utils/` — Utility functions.
- `src/layouts/` — Page layouts.
- `src/styles/` — Global and theme styles.
- `src/assets/` — Asset helpers and shared imports.

## Next Steps
